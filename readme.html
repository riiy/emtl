安装与支持范围¶

0.3.0 Stable 沿用已发布的 0.3.0b2 的功能基线， 不增加交易或 OCR 功能，支持 CPython 3.11、3.12、3.13 （Requires-Python >=3.11,<3.14）。 维护者曾在 Ubuntu x86_64、macOS Intel x86_64 六组 Python 环境中， 从 PyPI 安装 Beta 0.3.0b2 并分别完成 10 次真实账户登录， 共 60/60 次成功。该结果不是 0.3.0 Stable 的独立实盘验证， 更不证明所有 Linux/macOS 平台或真实交易获得生产保障； Apple Silicon、Windows、PyPy 尚未验证。

默认 OCR 为冻结微型 CNN（Pillow + Python 标准库），不会默认安装 ddddOCR、NumPy、ONNX Runtime 或 OpenCV。仅在 Python 3.11 可选安装 emtl[ddddocr] 并设置 EMTL_OCR_ENGINE=ddddocr； 显式选择失败不会静默回退。OCR v1 从 0.3.0b2 开始提供； 旧版 0.3.0b1 使用原 OCR。证据见 docs/refactor/reports/OCR-v1-acceptance.md 和 docs/refactor/reports/v0.3.0b2-beta-field-acceptance.md。

已发布的 Beta：0.3.0b1``（2026-11-10）、 ``0.3.0b2``（2026-11-14）。维护者于 2026-11-14 批准 不等待建议观察期而准备 Stable 候选。源码标记为 Stable 不等于 PyPI 已上架 ``0.3.0；应以 PyPI 上的实际发行记录为准。

在 0.3.0 正式上传 PyPI 后，可安装固定版本:

python -m pip install emtl==0.3.0

不指定版本时，pip 从 PyPI 选择符合环境约束的可用稳定版本:

python -m pip install emtl

仍可显式安装此前的 OCR Beta 进行比较:

python -m pip install --pre emtl==0.3.0b2

如需获取开发中的源码，可从仓库安装，但源码不等于已验证的正式发布版本:

python -m pip install https://github.com/riiy/emtl/archive/master.zip

Stable 是正式发行渠道，不意味着真实下单、撤单、成交或长期运行安全性已得到验证。 本项目仍是非官方接口，生产与投资风险免责声明继续适用。

Python 接口¶

emtl 提供两套兼容边界不同的接口：

  • 旧模块级函数：如 emtl.login() 和 emtl.create_order()。 这些函数复用进程级 Session 和认证令牌，保留历史行为，不保证多账户隔离。

  • ``emtl.TradingClient``：同步、显式绑定账户的客户端，独立管理 Session、Cookie 和 token。使用完毕须在 finally 中调用 close()； 当前不支持 with 或异步接口。

对于 TradingClient，交易 POST 开始尝试后若结果无法确定， 将抛出 emtl.errors.TradeOutcomeUnknown。 不得据此自动重发订单。 旧模块级函数不具备这项新异常契约。离线测试也不能证明真实券商已受理或成交。

命令行 emt 与 python -m emtl 当前只负责解析参数， 不会 实际登录、查询或提交交易。

开发与测试¶

开发及 CI 覆盖 CPython 3.11、3.12、3.13。自动测试只使用合成账户和禁网环境， 不连接真实券商，也不验证真实下单、撤单或成交结果。 SDK 不自动重试、重发或补偿订单。

在隔离测试环境中运行（完整离线验证需额外配置系统级禁网）:

python -m pip install -r ci/requirements.txt
tox

tox -e docs 生成 HTML；在线外链检查 tox -e linkcheck 独立执行，不属于离线测试。
