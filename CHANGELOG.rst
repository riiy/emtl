变更记录（Changelog）
============================

0.3.0b2 (OCR v1 Beta 候选；尚未发布)
----------------------------------------------------------------------------------

* 将已合并的 PR #32 的冻结微型 CNN + Pillow 设为默认 OCR；
  旧 ``ddddocr==1.4.11`` 调整为仅 Python 3.11 可用的可选 extra，
  引擎选择错误不静默回退。
* 保留四位数字验证码字符串及前导零；Python 支持范围扩至
  Linux CPython 3.11、3.12、3.13，不变更旧版交易接口签名。
* 冻结模型的一次性独立准确率验收为 96/100，前导零 10/10；
  目标 CPU P95 低于 1000 ms。参见 ``docs/refactor/reports/OCR-v1-acceptance.md``。
* 20 MB 安装体积门槛仅适用于目标机器源码编译 Pillow 的部署；
  普通用户安装官方 Wheel 允许超过该值。
* 此版本尚未创建 Tag、Release 或上传 PyPI，须完成精确 SHA 的
  master CI、发行包审计、独立 Review 和单独发布审批。

0.3.0b1 (2026-11-10 已发布的 PyPI Beta)
----------------------------------------------------------------

* 2026-11-10 已完成受控 Beta 发布；当时仅覆盖 P0–P3 及
  Linux CPython 3.11，不包含后续 OCR v1 改动。
* 首轮仅验证 **Linux / CPython 3.11** （``Requires-Python >=3.11,<3.12``）；
  Windows、macOS、PyPy 和 Python 3.12+ 不在验证/支持范围内。
* 包含 P0–P3 的安全加固、兼容保留、``TradingClient`` 多账户隔离以及
  ``TradeOutcomeUnknown`` / ``BrokerHTTPError`` 异常契约。
* 固定依赖仍为 ``rsa==4.9``、``requests==2.33.1``、
  ``ddddocr==1.4.11``、``cryptography==50.0.2``；
  Requests/cryptography 已进行定向安全修复和无网络兼容性验证。
* CLI ``emt`` 及 ``python -m emtl`` 仍只解析参数，不执行交易。
  不保证真实券商协议或实际成交；遇到交易结果不确定时不得自动重发订单。
* 仅提供中文 RST + Sphinx + HTML 文档；PyPI Beta 采用显式预发布安装。
  旧版 ``0.2.6`` 不具备本轮 P0–P3 保护，不能当作默认安全回退版本。

0.3.0a1 (未发布的内部 Alpha；目标正式版 0.3.0)
------------------------------------------------------------

* 保留旧版包级函数、CLI 签名、参数、退出码及成功响应结构；
  P0 已取消 CLI 凭证回显。
* 移除 SDK 中的敏感日志和 root logger 重配置，
  使用合成替身及系统级禁网隔离自动测试和 CI。
* P2 新增独立账户 ``TradingClient``，独立管理 HTTP/认证状态，
  同一账户在单进程内串行，不同账户允许并发。
* P3 为显式客户端增加 ``emtl.errors.TradeOutcomeUnknown``
  与 ``BrokerHTTPError``。Unknown 不代表成交或拒绝，不得自动重发；
  旧模块级接口异常行为保持不变。
* 已批准的支持目标缩小为 Linux / CPython 3.11
  （``Requires-Python >=3.11,<3.12``）；
  保留 ``ddddocr==1.4.11`` 及已批准的运行时依赖固定版本。
* 增加发布产物安装验证与受人工审批保护的发布流程。
  自动化测试未验证真实券商协议或实际交易。
* 计划 PyPI Beta ``0.3.0b1``，必须另行批准上传；
  正式版 ``0.3.0`` 需 Beta 后单独决策。
  尚未承诺发布日期或生产可用性。
