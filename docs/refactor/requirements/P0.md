
# P0 安全基线

## 目标

1. 清除敏感日志。
2. 隔离自动测试与真实交易。
3. 确定现有公共 API 契约。
4. 保留真实下单调用方式。

## Plan

重点检查：
- src/emtl/core.py
- src/emtl/utils.py
- src/emtl/__init__.py
- src/emtl/tests/
- .github/workflows/

枚举公共 API、敏感信息传播路径、
真实交易测试和 CI 凭证配置。

设计实施步骤、测试及回滚策略。

## Build

1. 固化公共 API 契约。
2. 清理敏感日志。
3. 修复 logging 全局配置副作用。
4. 隔离真实交易测试。
5. 移除 CI 的账户凭证注入。
6. 添加离线安全回归测试。

禁止改变真实交易调用语义。

## Review

检查：
1. 敏感信息是否仍可能泄漏。
2. 自动测试是否可能触发真实交易。
3. CI 是否仍使用真实账户凭证。
4. API 签名和返回结果是否改变。
5. logging 修改是否产生回归。

## 验收标准

- 无敏感日志泄漏。
- 自动测试不会访问真实券商。
- CI 不使用真实账户。
- 旧 API 保持兼容。
- 公共 API 契约已形成文档。
